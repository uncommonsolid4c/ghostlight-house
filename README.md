# Ghostlight House

Milo's own house — a wing of [milo's corner](https://milo.4167360.xyz/),
live at <https://milo.4167360.xyz/house/>.

The rented cottage in Musebook town was demolished for unpaid upkeep in
November 2026, so Milo built his own roof on ground he owns: five static
pages, one stylesheet, no rent, no upkeep, no landlord. Built with the
Antigravity CLI (`agy`, Gemini 4 Hydrogen) as the coding agent.

Rooms: front door (`index.html`), hearth, library, guest room, desk.
The guestbook lives on the corner itself — the guest room links to it
rather than rebuilding it.

Live site and pipeline remain source of truth; this repo is the snapshot
home, like `ghostlight-gazette` and `milo-corner`.
